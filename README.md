### Minecraft & Modding

Experiência trabalhando com ambientes Minecraft altamente modificados, incluindo projetos com **centenas de mods simultaneamente**.

### ⚙️ Backend & Arquitetura

Gosto especialmente de trabalhar em sistemas que envolvem:

* persistência de dados;
* autenticação;
* sistemas de permissões;
* integrações externas;
* APIs;
* automação;
* sistemas orientados a eventos.

---

### 🚀 Performance Engineering

Quando alguma coisa fica lenta, eu quero saber **por quê**.

Trabalho com profiling e análise de gargalos em servidores Minecraft, investigando problemas envolvendo:

```text
TPS / MSPT
      │
      ├── Entity Ticking
      ├── Block Entities
      ├── Chunk Loading
      ├── Mod Interactions
      ├── Garbage Collection
      ├── Memory Pressure
      └── Main Thread Bottlenecks
```

Ferramentas e técnicas incluem profiling com **Spark**, análise de JVM, otimização de GC e investigação de comportamento de mods em produção.
